# Rickovns Roleplay

Русскоязычный сайт CRMP-проекта с главной страницей, магазином и личным кабинетом. Чтобы посмотреть сайт на компьютере, открой `index.html`. Установка пакетов и сборка не требуются.

## Публикация через GitHub Pages

1. Распакуй архив сайта на компьютере.
2. Создай публичный репозиторий на GitHub, например `rickovns-site`.
3. Открой загрузку файлов (Upload files) и перетащи содержимое распакованной папки вместе с каталогом `assets`. Файл `index.html` должен лежать в корне репозитория. Сохрани изменения в ветке `main` кнопкой **Commit changes**.
4. В **Settings → Pages** выбери **Deploy from a branch**, ветку **main** и папку **/(root)**. Нажми **Save**.
5. Когда публикация завершится, открой **Visit site** в настройках Pages. Проверь переходы с главной в магазин и кабинет.

## Настройки сайта

В `app.js` поля `downloadUrl` и `forumUrl` задают ссылки на лаунчер и форум. В объекте `communityLinks` находятся Telegram и Discord проекта, а поле `support` предназначено для ссылки на поддержку.

Магазин и кабинет работают в демонстрационном режиме. Данные профиля и заказы сохраняются в браузере. Для реального приёма оплаты и выдачи покупок в игре потребуется отдельный серверный обработчик и интеграция с игровым модом.

## Оформление

Основные тексты находятся в `index.html`, `donate.html` и `account.html`. Общие стили находятся в `styles.css` и `redesign.css`. Анимация фона вынесена в `pixel-blast.js`, каталог машин — в `vehicles.js`. Изображения проекта хранятся в `assets/`. Для внешних шрифтов и некоторых фоновых изображений требуется интернет.
