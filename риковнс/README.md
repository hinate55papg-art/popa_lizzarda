# Rickovns Roleplay — сайт проекта

Адаптивная русскоязычная главная страница для CRMP проекта Rickovns. Открой `index.html` в браузере или размести все файлы из этой папки на веб-хостинге.

## Подключение проекта

Открой `app.js` и заполни адреса сайта и сообщества в `RICKOVNS_CONFIG`:

- `downloadUrl` — ссылка на лаунчер или страницу скачивания;
- `forumUrl` — адрес форума или сообщества;
- `checkoutUrl` в `donate.js` — адрес магазина/платёжной страницы для покупки Coins. Выбранное количество будет передано в параметре `coins`.

Пока адреса не заполнены, кнопки показывают посетителю понятное сообщение. В магазине работают переключение категорий, добавление пакетов в корзину, изменение количества и удаление. Для реальной покупки Coins потребуется подключить платёжный сервис, настроить цены, серверную обработку платежей и зачисление валюты в аккаунт игрока. Отдельная витрина находится в `donate.html`, её оформление — в `donate.css`.

## Анимации

Для появления элемента при прокрутке добавь `data-animate="rise"` в HTML. Главный фон медленно двигается и приближается, заголовок появляется при загрузке, карточки раскрываются при прокрутке, а тонкая полоса сверху показывает прогресс страницы. Эффекты заданы в `styles.css`, логика — в `app.js`; настройка `prefers-reduced-motion` отключает движение для тех, кто его ограничивает.

В блоке «Кем ты станешь?» можно выбрать роль: полицейский, мафиози, медик, предприниматель или свободный житель. Выбор меняет описание пути на странице.
